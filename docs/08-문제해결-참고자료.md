# 8장. 문제 해결과 참고 자료

## 8.1 자주 발생하는 오류와 대처

### 8.1.1 모델 로드 단계

**증상**: *"Failed to connect Socket 'parent_frame' of type PhysicalFrame..."*
- **원인**: 모델 XML에서 참조한 Body 이름이 존재하지 않음.
- **해결**: XML 직접 편집 또는 GUI에서 해당 Joint의 frame을 재지정.

**증상**: 분홍색 박스가 표시되고 Body 형상이 보이지 않음.
- **원인**: `Geometry/` 파일 경로 누락.
- **해결**: [5.6](05-모델-탐색.md#56-geometry-경로-문제-해결) 참고. 환경변수 `OPENSIM_GEOMETRY_PATH` 또는 모델 옆 `Geometry/` 복사.

### 8.1.2 Scale 단계

**증상**: Scale factor가 비현실적으로 큰/작음.
- **원인**: 마커 페어가 잘못 지정, TRC 단위(mm vs m) 불일치.
- **해결**: 정적 시점의 마커 위치를 3D 뷰에서 직접 확인. TRC 헤더의 `Units` 확인.

### 8.1.3 IK 단계

**증상**: Marker error가 비정상적으로 큼 (> 5 cm).
- **원인**: 마커 이름 불일치, 좌표계 불일치, 모델 마커 위치 오류.
- **해결**:
  1. TRC 파일과 모델 마커 이름이 정확히 같은지 확인.
  2. **Coordinate Frame Conversion** (모션캡처 → OpenSim) 적용 여부 확인.
  3. 시간이 진행될수록 오차가 커지면 마커 추적 오류(스와핑 등) 의심.

### 8.1.4 ID 단계

**증상**: 모멘트 그래프에 큰 잡음.
- **원인**: 필터 미적용.
- **해결**: ID 설정에서 Low-pass filter cutoff = 6 Hz (보행 기준) 적용.

**증상**: 큰 잔차(residual force/moment).
- **원인**: 모델 질량/관성 부정확, GRF 데이터 노이즈, 좌표계 불일치.
- **해결**: **RRA(Residual Reduction Algorithm)** 으로 보정 또는 모델 검증.

### 8.1.5 CMC 단계

**증상**: *"CMC failed to converge"*
- **원인**: 시간 스텝이 너무 크거나 reserve actuator가 너무 약함.
- **해결**:
  1. **Use Fast Target** 옵션 활성화.
  2. Reserve actuator의 `optimal_force` 상향, 또는 가중치(weight)를 일시적으로 낮춤.
  3. 분석 시간을 짧게 잘라 단계적으로 실행.

### 8.1.6 메모리·성능

- **증상**: GUI가 응답 없음/크래시.
- **해결**:
  - `Edit → Preferences → JVM` 에서 최대 힙 메모리 상향 (예: `-Xmx8g`).
  - 대형 모션 파일은 분할하여 처리.
  - 시각화 품질을 낮춤(`Preferences → Visualization → Quality`).

## 8.2 디버깅 팁

1. **Messages 창**을 항상 주시 — 경고·오류가 모두 여기 표시된다.
2. 각 도구의 **설정 XML을 저장** — 동일 조건 재현, 동료와 공유에 유용.
3. **버전을 명시** — 보고/논문에서 OpenSim 버전을 명시한다 (예: "OpenSim 4.5.2").
4. **단순한 모델로 검증** — 새 워크플로는 Arm26 같은 단순 모델에서 먼저 시험.
