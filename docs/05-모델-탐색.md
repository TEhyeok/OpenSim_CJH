# 5장. 모델 탐색과 조작

본 장은 Navigator, Properties, Coordinates 윈도우를 활용해
모델 내부 구조를 이해하고 간단한 편집을 수행하는 방법을 다룬다.

## 5.1 모델 트리 구조 이해

OpenSim 모델은 계층적인 컴포넌트로 구성된다. Navigator에서 가장 흔히 보게 되는 구조는 다음과 같다.

```
<model>.osim
├── Bodies              # 강체 — 골반, 대퇴, 정강이, 발 등
├── Joints              # 관절 — 각 Body 사이의 연결
├── Constraints         # 운동 구속 (예: PointConstraint)
├── Forces              # 힘 — Muscle, ExternalForce, Spring, Damper
├── Markers             # 모션캡처 마커 부착점
├── ContactGeometries   # 접촉 형상 — 발-바닥 접촉 등
├── Controllers         # 시간에 따른 액추에이터 제어 신호
├── Probes              # 적분/누적 변수 출력기
└── ComponentSet (custom plug-ins 등)
```

### 트리 노드 우클릭 기능

| 메뉴 | 설명 |
| ---- | ---- |
| Edit | 속성 편집 (Properties 윈도우 활성화) |
| Disable / Enable | Force·Constraint 일시 비활성화 |
| Delete | 컴포넌트 제거 (주의: 의존 컴포넌트 함께 영향) |
| Add → Body / Joint / Marker... | 새 컴포넌트 추가 |
| Show in Visualizer | 3D 뷰에서 강조 표시 |

## 5.2 Body와 Joint 살펴보기

### 5.2.1 Body의 주요 속성

`mass`, `mass_center`, `inertia`(`Ixx, Iyy, Izz, Ixy, Ixz, Iyz`), 부착된 **Visual Geometry** 파일.

> Visual Geometry는 `Geometry/` 폴더의 `.vtp` 또는 `.stl` 파일을 참조한다.
> 경로가 깨지면 3D 뷰에 분홍색 placeholder가 표시된다.

### 5.2.2 Joint 종류

| Joint 타입 | DOF | 사용 예 |
| ---------- | --- | ------- |
| `FreeJoint` | 6 (3R + 3T) | 골반-Ground (보행 모델) |
| `BallJoint` | 3 (3R) | 어깨, 고관절 |
| `PinJoint` | 1 (1R) | 팔꿈치, 무릎 (단순화) |
| `SliderJoint` | 1 (1T) | 직선운동 |
| `CustomJoint` | 1~6 | 무릎 등 복잡한 운동학 — SpatialTransform로 정의 |
| `WeldJoint` | 0 | 두 Body 고정 결합 |

### 5.2.3 CustomJoint와 SpatialTransform

CustomJoint는 각 회전/병진 축에 대해 **Coordinate**와 **TransformAxis function**을 지정하여
복잡한 운동학(예: 무릎의 회전축 이동)을 표현한다.
간단한 분석에서는 기존 정의를 그대로 사용하면 된다.

## 5.3 Coordinates: 자유도 다루기

### 5.3.1 Coordinate 속성

- **range** — 허용 범위 (rad 또는 m)
- **default_value** — 모델 로드 시 기본 자세
- **clamped** — 범위 강제 적용 여부
- **locked** — IK 등에서 잠금
- **prescribed** — 시간 함수로 외부 지정
- **prescribed_function** — `Constant`, `LinearFunction`, `SimmSpline` 등

### 5.3.2 활용 팁

- IK 수행 시 **clamped = true** 가 권장된다 (비현실적 각도 방지).
- 보행 분석에서 골반-Ground FreeJoint의 6 DOF는 보통 **unlocked / unclamped**.
- 잠시 특정 관절을 고정하고 싶다면 슬라이더 우측의 자물쇠 아이콘을 클릭한다.

## 5.4 Forces (근육·외력) 탐색

Forces 폴더에는 다음이 포함된다.

### 5.4.1 Muscles (Hill 모델 계열)

| 클래스 | 특징 |
| ------ | ---- |
| `Thelen2003Muscle` | 가장 널리 쓰이는 표준 모델 |
| `Millard2012EquilibriumMuscle` | 안정성·미분 가능성 개선 |
| `DeGrooteFregly2016Muscle` | Moco용, smooth 곡선 |

근육 선택 시 Properties 창에서 다음 핵심 파라미터를 확인할 수 있다.

- `max_isometric_force` — 최대 등척성 힘 (N)
- `optimal_fiber_length` — 최적 근섬유 길이 (m)
- `tendon_slack_length` — 건의 늘어지지 않는 길이 (m)
- `pennation_angle_at_optimal` — 최적 깃각 (rad)
- `GeometryPath` — 근육 경로 (PathPoints + Wrapping)

### 5.4.2 ExternalForce

지면반력(GRF) 등 외력은 보통 `ExternalForce`로 정의한다.
`ExternalLoads.xml` 파일에 다음 정보가 들어있다.

```xml
<ExternalForce name="grf_r">
  <applied_to_body>calcn_r</applied_to_body>
  <force_expressed_in_body>ground</force_expressed_in_body>
  <point_expressed_in_body>ground</point_expressed_in_body>
  <data_source_name>grf.mot</data_source_name>
  <force_identifier>ground_force_v</force_identifier>
  <point_identifier>ground_force_p</point_identifier>
</ExternalForce>
```

## 5.5 Markers: 마커 편집

- `Markers` 폴더에서 각 마커를 더블클릭 → Properties에 부착 Body 이름과 local position 표시.
- 3D 뷰어에서 마커를 직접 드래그하여 위치 미세조정 가능.
  - **Edit → Marker Picking Mode** 활성화 후 마우스로 드래그.
- 새 마커 추가: `Markers` 우클릭 → *Add Marker* → Body 선택 → 위치 입력.
- Scale Tool 사용 전 모델 마커셋이 실험 마커셋과 **이름이 같은지** 반드시 확인.

## 5.6 Geometry 경로 문제 해결

모델 파일은 형상 파일을 상대 경로로 참조한다. 폴더 위치가 다르면 분홍색 placeholder가 표시된다.

해결 방법:
1. `Edit → Preferences → Geometry Path` 에서 검색 경로 추가.
2. 또는 모델 폴더 옆에 `Geometry/` 폴더를 복사한다.
3. 환경변수로 지정:
   - Windows: `OPENSIM_GEOMETRY_PATH=C:\OpenSim 4.5\Geometry`
   - macOS/Linux: `export OPENSIM_GEOMETRY_PATH=/path/to/Geometry`

## 5.7 모델 비교·병합

GUI에서 두 개 이상의 모델을 열어 시각적으로 비교할 수 있다.

- **File → Open Model...** 으로 두 번째 모델을 추가 로드.
- Navigator에서 두 모델 모두 트리에 표시된다.
- 한 화면에 겹쳐 표시되므로, 우클릭 → *Set Color* 로 색을 다르게 지정하면 비교가 쉽다.

본격적인 병합·차분은 XML 편집기나 Python 스크립트가 더 효율적이다.

## 5.8 모델 편집 시 주의사항

1. **백업 후 편집** — 원본 `.osim`을 보존하고 사본을 편집한다.
2. **단위 일관성** — OpenSim 기본 단위는 **m, kg, N, rad, s**. 마커 데이터 단위(mm vs m)에 주의.
3. **좌표계** — OpenSim 표준은 **y-up, x-forward, z-right** (오른손 좌표계).
   모션 캡처 데이터의 좌표계와 다르면 회전 변환 필요.
4. **저장 후 재로드** — 변경 사항이 실제 반영됐는지 모델을 닫았다 다시 열어 확인.
