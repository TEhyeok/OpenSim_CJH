# 2장. 설치 가이드

본 장에서는 OpenSim 4.5 GUI의 운영체제별 설치 방법을 설명한다.
스크립팅(Python/MATLAB) 환경 설정은 6장 마지막 절을 참고하라.

## 2.1 시스템 요구사항

| 항목 | 최소 | 권장 |
| ---- | ---- | ---- |
| OS | Windows 10 (64-bit) / macOS 10.15+ / Ubuntu 20.04+ | Windows 11 / macOS 13+ / Ubuntu 22.04 |
| CPU | x86-64 듀얼코어 | 쿼드코어 이상 (Apple Silicon은 Rosetta로 동작) |
| RAM | 8 GB | 16 GB 이상 |
| 디스크 | 4 GB 여유 공간 | 10 GB (예제·결과 저장 포함) |
| GPU | OpenGL 3.3 지원 | 전용 GPU (대형 모델 시각화에 유리) |
| 디스플레이 | 1280×800 | 1920×1080 이상 |

> 4.5.2 기준. 최신 요구사항은 [GitHub 릴리스 페이지](https://github.com/opensim-org/opensim-core/releases)에서 확인한다.

## 2.2 다운로드

1. <https://simtk.org/projects/opensim> 접속
2. **Download** 탭 → `OpenSim 4.5` 선택
3. SimTK 계정으로 로그인 (무료 가입) 후 라이선스 동의
4. 운영체제에 맞는 인스톨러 다운로드
   - Windows: `OpenSim-4.5.x-win64.exe`
   - macOS: `OpenSim-4.5.x-mac.dmg`
   - Linux: `.deb` 패키지 또는 소스 빌드

## 2.3 Windows 설치

### 2.3.1 단계별 절차

1. 다운받은 `.exe` 파일을 **우클릭 → 관리자 권한으로 실행**.
2. 보안 경고가 뜨면 *Run anyway* 선택.
3. 설치 마법사에서 다음 옵션을 확인한다.
   - **Install Path**: 기본값 `C:\OpenSim 4.5\` 권장 (공백 없는 경로가 안전)
   - **Add to PATH**: ✅ 체크 (명령줄·스크립트 사용 시 필수)
   - **Install Examples**: ✅ 체크 (`Models/`, `Geometry/` 폴더 포함)
4. 설치 완료 후 시작 메뉴에서 **OpenSim 4.5 GUI** 실행.

### 2.3.2 설치 확인

명령 프롬프트(`cmd`)에서 다음을 입력:

```bash
opensim-cmd --version
```

`OpenSim version: 4.5.x` 메시지가 출력되면 정상이다.

### 2.3.3 자주 발생하는 문제

- **`MSVCP140.dll`이 없다는 오류** → Microsoft Visual C++ 2015–2022 재배포 패키지를 설치한다.
- **GUI가 검은 화면으로 시작** → 그래픽 드라이버 업데이트, 또는 `OpenSim 4.5 GUI.exe`를 우클릭하여
  *고성능 GPU로 실행*으로 설정한다.

## 2.4 macOS 설치

### 2.4.1 단계별 절차

1. `.dmg` 파일을 더블클릭하여 마운트한다.
2. `OpenSim.app`을 `/Applications` 폴더로 드래그한다.
3. **첫 실행 시** Finder에서 우클릭 → *Open* 을 선택 (Gatekeeper 우회).
4. *허용되지 않은 개발자* 경고가 뜨면, *시스템 설정 → 개인정보 보호 및 보안* 에서 **허용** 버튼 클릭.

### 2.4.2 Apple Silicon (M1/M2/M3) 주의사항

OpenSim 4.5는 **x86-64 빌드**가 공식 제공된다. Apple Silicon Mac에서는 **Rosetta 2**로 동작한다.

```bash
softwareupdate --install-rosetta --agree-to-license
```

네이티브 ARM 빌드는 커뮤니티에서 시험 중이며, 안정적 사용은 conda 환경의 Python 인터페이스를 권장한다.

### 2.4.3 명령줄 도구 등록

`~/.zshrc` 또는 `~/.bash_profile`에 다음을 추가한다.

```bash
export PATH="/Applications/OpenSim 4.5/Contents/Resources/OpenSim/bin:$PATH"
```

## 2.5 Linux (Ubuntu/Debian) 설치

### 2.5.1 deb 패키지 설치

```bash
# 다운로드한 패키지 위치로 이동 후
sudo apt update
sudo apt install ./opensim-4.5.x-linux.deb
```

의존 라이브러리(`libblas`, `liblapack`, `libgl1` 등)는 apt가 자동으로 해결한다.

### 2.5.2 GUI 실행

```bash
opensim
```

GUI가 뜨지 않으면 `LD_LIBRARY_PATH`를 확인한다.

```bash
export LD_LIBRARY_PATH=/opt/opensim-4.5/lib:$LD_LIBRARY_PATH
```

### 2.5.3 소스에서 빌드 (선택)

연구 환경상 필요한 경우, [opensim-core 빌드 가이드](https://github.com/opensim-org/opensim-core?tab=readme-ov-file#on-ubuntu-using-source)를 참고한다.
필요 패키지 예시:

```bash
sudo apt install build-essential cmake git \
  liblapack-dev libblas-dev libxi-dev libxmu-dev \
  freeglut3-dev libssl-dev libpcre2-dev autoconf libtool pkg-config
```

## 2.6 설치 후 폴더 구조

기본 설치 경로(Windows 기준 `C:\OpenSim 4.5\`) 아래에는 다음 폴더가 생성된다.

```
OpenSim 4.5/
├── bin/                # 실행 파일 (opensim, opensim-cmd, ik, id 등)
├── lib/                # 동적 라이브러리
├── sdk/                # SDK (C++ 헤더, Python·MATLAB 바인딩)
├── Models/             # 예제 모델 (Arm26, Gait2354, Leg6Dof9Musc 등)
├── Geometry/           # VTP/STL 형상 파일
├── Resources/          # 도구 설정 템플릿
└── Documentation/      # PDF, 예제 시나리오
```

이 중 **Models/** 와 **Geometry/** 폴더 경로는 자주 참조하므로 위치를 기억해두자.

## 2.7 업그레이드 / 제거

- **업그레이드**: 새 버전 인스톨러를 실행하면 기존 버전과 별개로 설치된다. 사용자 모델은
  `Documents/OpenSim/` 등 별도 위치에 저장하는 것이 안전하다.
- **제거**: Windows는 *프로그램 추가/제거*, macOS는 `OpenSim.app` 휴지통 이동,
  Linux는 `sudo apt remove opensim`.
