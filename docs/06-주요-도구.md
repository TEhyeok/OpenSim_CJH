# 6장. 주요 분석 도구

OpenSim의 `Tools` 메뉴에는 연구에 핵심적인 분석 도구가 모여 있다.
본 장은 각 도구의 입력·출력·실행 절차·주요 옵션과 결과 해석 포인트를 정리한다.

> 본 장은 **사용법 중심**이다. 알고리즘의 수학적 배경은 OpenSim 공식 위키
> (`Documentation > Tools` 섹션)와 Delp et al. (2007), Seth et al. (2018) 논문을 참조하라.

---

## 6.1 Scale Tool — 모델 스케일링

피험자의 신체 분절 길이에 맞게 일반 모델(generic model)을 조정한다.

### 입력
- **Generic Model** (`.osim`)
- **Static Trial 마커 데이터** (`.trc`) — 피험자가 정자세로 선 짧은 시간 측정
- **Scale Setup 파일** (`.xml`, 선택)
- (선택) **수기 측정값** — 양 어깨 너비 등

### 출력
- **Scaled Model** (`.osim`)
- **Scaled Marker Set** — 모델 마커가 정적 시점에서 실험 마커와 일치하도록 조정

### 실행 절차
1. `Tools → Scale Model...`
2. **Subject Data** 탭에서 피험자 질량 입력.
3. **Scale Factors** 탭에서 분절별 마커 쌍 정의 (예: `LASI-RASI` 으로 골반 폭).
4. **Marker Placer** 탭에서 정적 시점의 마커 위치로 모델 마커를 보정.
5. **Output** 탭에서 저장 경로 지정.
6. **Run** 클릭.

### 체크포인트
- Messages 창에서 **Marker error** 값이 합리적인 범위(보통 1cm 미만)인지 확인.
- 모델 마커가 피험자 자세에서 실제 마커 근처에 위치하는지 3D 뷰에서 확인.
- 스케일이 0.5~2.0 범위를 크게 벗어나면 데이터·페어링 오류를 의심.

## 6.2 Inverse Kinematics (IK)

마커 궤적으로부터 관절 각도를 계산한다. 각 프레임마다 다음 가중 최소제곱 문제를 푼다.

$$
\min_q \sum_{i \in markers} w_i \| x_i^{exp} - x_i^{model}(q) \|^2
+ \sum_{j \in coords} w_j (q_j^{exp} - q_j)^2
$$

### 입력
- **Scaled Model** (`.osim`)
- **Marker Trajectory** (`.trc`)
- (선택) **Coordinate Data** (`.mot`) — 특정 자유도를 직접 측정한 경우

### 출력
- **Joint Angles** (`.mot`)

### 실행 절차
1. `Tools → Inverse Kinematics...`
2. **Marker File** 지정.
3. **Time Range** 설정 (관심 시간 구간만).
4. **Marker Weights** 검토. 잡음이 큰 마커는 가중치 ↓.
5. **Output Motion File** 지정 → **Run**.

### 결과 해석
- Messages 창의 **Total Marker Error (RMS / max)**:
  - 보행 분석에서 RMS < 2cm, max < 4cm 를 일반적 기준으로 본다.
- 큰 오차의 마커는 별도로 표시되므로 데이터 품질을 점검한다.

## 6.3 Inverse Dynamics (ID)

관절 각도와 외력을 입력으로 받아 각 관절에 작용한 **모멘트(net joint torque)** 를 산출한다.

### 입력
- **Model** (`.osim`)
- **Motion** (`.mot`) — 보통 IK 결과
- **External Loads** (`.xml`) — GRF 정의 파일

### 출력
- **Joint Moments** (`.sto`)

### 실행 절차
1. `Tools → Inverse Dynamics...`
2. **Motion File** 지정.
3. **External Loads File** 지정 (GRF가 있을 경우).
4. **Filter** — Low-pass cutoff (Hz). 보통 보행은 6 Hz.
5. **Time Range** 설정.
6. **Run**.

### 주의 포인트
- **Filter 누락**은 모멘트 그래프에 큰 잡음으로 이어진다.
- **GRF와 모델 좌표계 일치** 여부를 반드시 확인.
- 결과는 **net torque**이므로 근육별 기여를 알려면 SO/CMC가 필요하다.

## 6.4 Static Optimization (SO)

각 시점에서 관절 모멘트를 만족하는 근육 활성도를 **순간적으로(instantaneous)** 최적화한다.
보통 활성도 제곱합 최소화를 목표로 한다.

### 입력
- **Model**, **Motion**, **External Loads** (ID와 동일)

### 출력
- 근육별 **활성도(activation)** 와 **힘(force)** 시계열 (`.sto`)

### 실행 절차
1. `Tools → Static Optimization...`
2. **Motion / External Loads** 지정.
3. **Use Muscle Force-Length-Velocity Relations** 체크 (현실적 결과).
4. **Activation Exponent** — 보통 2 (제곱합).
5. **Reserve Actuator** — 부족한 모멘트를 보충 (CoordinateActuator). 보통 큰 페널티(1000)로 설정.
6. **Run**.

### 결과 해석
- **활성도가 1.0에 자주 도달**한다면 모델 근력 부족 또는 잘못된 외력일 수 있다.
- Reserve actuator 값이 크면 모델·데이터 불일치를 시사한다.

---

## 6.5 Computed Muscle Control (CMC)

근육-건 동역학(activation/contraction dynamics)을 고려하여,
짧은 시간 윈도 안에서 PD 제어로 추종하면서 활성도를 최적화한다.

### 입력
- **Model**, **Desired Kinematics** (`.mot`), **External Loads** (`.xml`)
- **Actuators** (`.xml`) — Reserve actuators 정의
- **Tracking Tasks** (`.xml`) — 각 자유도 추종 가중치

### 출력
- 근육 **활성도 / 컨트롤 신호**, **상태 변수** (`.sto`)

### 실행 절차
1. `Tools → Computed Muscle Control...`
2. 모든 설정 파일을 지정한다.
3. **Use Fast Target** 체크 (수렴 가속).
4. **Time Range** 설정 — 통상 IK 구간보다 약간 짧게.
5. **Run** — 시간이 오래 걸린다 (모델 크기에 따라 수 분 ~ 1시간).

### 활용 팁
- CMC는 SO보다 **시간 평활**하고 동적 근육 거동을 반영하지만, 수렴이 까다롭다.
- 처음 1~2초의 **transient**가 발생할 수 있어, 분석 구간 앞에 여유를 둔다.

---

## 6.6 Forward Dynamics (FD)

근육 활성도 또는 컨트롤 신호를 입력으로 **운동을 적분 시뮬레이션** 한다.

### 입력
- **Model** + **Controls File** (`.sto`) + 외력
- **Initial States** (`.sto`, 선택)

### 출력
- **State** 시계열 — 관절각, 근육 활성도/섬유 길이 등

### 실행 절차
1. `Tools → Forward Dynamics...`
2. 컨트롤 파일과 초기 상태 지정 (없으면 기본값 사용).
3. **Integrator Settings** — Accuracy `1e-5` 기본.
4. **Run**.

### 활용 예
- CMC 결과 컨트롤로 동일 운동이 재현되는지 검증
- 가상적 액추에이션(예: 보조기 토크) 추가 시 운동 예측

## 6.7 Analyze Tool

다양한 분석을 한 번에 실행한다.

| Analysis | 출력 |
| -------- | ---- |
| `MuscleAnalysis` | 근육 길이, 모멘트암, FL/FV 곡선값 |
| `BodyKinematics` | Body의 위치/속도/가속도 |
| `JointReaction` | 관절 반력·반모멘트 |
| `StaticOptimization` | SO 분석 출력 (도구에서도 실행 가능) |
| `ForceReporter` | 모든 Force의 시계열 |
| `Kinematics` | 관절각/각속도/각가속도 |
| `PointKinematics` | 임의 점의 운동학 |

### 실행 절차
1. `Tools → Analyze...`
2. **Coordinates / States File** 지정.
3. **Analyses** 탭에서 원하는 분석을 추가/활성화.
4. **Run** → 각 분석 결과가 별도 `.sto`로 저장됨.

> **JointReaction**은 관절 반력 분석의 핵심 도구로, 무릎/고관절 부하 평가에 자주 사용된다.

## 6.8 Moco — 최적제어 기반 예측 시뮬레이션

OpenSim Moco는 **direct collocation** 기법으로 최적제어 문제를 푼다.
주된 사용 사례:

- 데이터 추종(tracking) 시뮬레이션 — IK/CMC 대체
- **예측(predictive)** 시뮬레이션 — "이 사람이 만약 X 조건에서 걷는다면?"
- 모델 파라미터 최적화

### GUI 통합 현황
Moco는 주로 **Python/MATLAB 스크립트**로 사용된다. GUI에서도 일부 기본 문제 실행이 가능하지만,
연구에서는 스크립트 사용을 권장한다.

### Python 최소 예제

```python
import opensim as osim

study = osim.MocoStudy()
problem = study.updProblem()
problem.setModel(osim.Model("subject_scaled.osim"))
problem.setTimeBounds(0, 1.0)

problem.setStateInfo("/jointset/hip_r/hip_flexion_r/value",
                     [-0.5, 0.5], 0.0, 0.0)
# ... 다른 상태/컨트롤 경계 설정 ...

problem.addGoal(osim.MocoControlGoal("effort", 1.0))

solver = study.initCasADiSolver()
solver.set_num_mesh_intervals(50)

solution = study.solve()
solution.write("moco_solution.sto")
```

자세한 내용은 [Moco 공식 문서](https://opensim-org.github.io/opensim-moco-site/)를 참고하라.

## 6.9 명령줄(opensim-cmd)에서 실행

모든 도구는 명령줄에서도 실행할 수 있다 — 배치 처리·HPC에 유용.

```bash
# IK
opensim-cmd run-tool ik_setup.xml

# ID
opensim-cmd run-tool id_setup.xml

# Analyze
opensim-cmd run-tool analyze_setup.xml

# 모델 정보 출력
opensim-cmd info model subject.osim
```

GUI에서 도구를 설정한 후 **Save Settings...** 으로 `.xml`을 저장하면 그대로 명령줄에서
재사용할 수 있다.

## 6.10 Python / MATLAB 스크립팅 환경

### Python (conda 권장)

```bash
conda create -n opensim python=3.11
conda activate opensim
conda install -c opensim-org opensim
```

설치 확인:

```python
import opensim as osim
print(osim.__version__)
model = osim.Model("Arm26/arm26.osim")
state = model.initSystem()
print(model.getNumCoordinates(), "DOFs")
```

### MATLAB

OpenSim 설치 폴더의 `Resources/Code/Matlab/configureOpenSim.m` 실행 후 MATLAB 재시작.

```matlab
import org.opensim.modeling.*
model = Model('Arm26/arm26.osim');
state = model.initSystem();
disp(model.getNumCoordinates())
```
